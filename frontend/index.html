How to Use

Step-by-step tutorials for setting up and managing your store with AliSync.

Your AliSync guide

Connect your accounts, choose a plan, and import your first product. Expand any tutorial below for the steps.

01. Start here: your first import
  1. Create your AliSync account, verify your email, and sign in.
  2. Connect Shopify and AliExpress using the next two tutorials. When both connections are ready, continue to plans.
  3. Choose a plan, then check the active store in the top-right store selector.
  4. Open Fetch & Import, paste an AliExpress product ID or URL, and fetch the product.
  5. Review the result, import it to Shopify, then manage it in Imported Products.

Use the tutorials below whenever you need help with pricing, stock, existing products, or supplier changes.

02. Get and add Shopify credentials
  1. Open the Shopify Dev Dashboard with app development permissions. Create an app in the same organization as your store.
  2. Create and release an app version. Configure product read/write access, plus inventory and location access for stock synchronization. Approve the permissions when installing or updating the app on the exact store you will connect.
  3. In the app settings, copy the Client ID and Client Secret.
  4. In AliSync, select Connect Shopify during setup or Authenticate Shopify in the account connections banner.
  5. Enter your your-store.myshopify.com domain, Client ID, and Client Secret. Select Save & Authenticate and check that Shopify shows connected.

This app uses Shopify's client credentials flow: the app and store must belong to the same organization.

Official Shopify app setup guide · Connection requirements

03. Get and add AliExpress credentials
  1. Sign in to the AliExpress Open Platform. Complete the developer registration and app approval required for your account, and obtain access to the product/dropshipping APIs used by your integration. Available options depend on your account's approval.
  2. Open your developer app and locate its App Key and App Secret. These are app credentials, not your AliExpress account password.
  3. In AliSync, select Connect AliExpress or Authenticate AliExpress. Use the callback URL shown in the form and register that exact URL in your AliExpress app. If the field is blank, ask your app administrator for the deployed callback URL.
  4. Enter the App Key, App Secret, and Registered callback URL. Select Save & Authenticate.
  5. Authorize access in the new AliExpress tab. Copy the code value from the callback page or URL, return to AliSync, paste it into the authorization-code field, and select Connect AliExpress.
  6. Check that the account connections banner shows AliExpress connected.

If authorization fails, check the exact callback URL, app approval/API access, and credentials. Start authorization again if the code has expired or was already used.

04. Select a plan and product access
  1. Open Plans & Product Access and compare the current prices, limits, and features shown on the cards.
  2. Free supports a limited product catalog with full features on the first eligible products. Growth supports unlimited sourcing with full features on selected products. Pro provides full features for all products. Use the plan cards for the current allowances.
  3. Select Start Free or Choose for your preferred plan. The selected card will show Current plan.
  4. Review your usage and product access. A Basic access product can be imported or mapped, but pricing and inventory tools require full access. On Growth, use the product access controls to choose eligible products.
05. Fetch and import new products
  1. Select the destination store in the top bar, then open Fetch & Import.
  2. Paste AliExpress product IDs or product URLs into the input and select Fetch Products.
  3. Review each product's title, image, price, and variants. Select Import to Shopify for one product or Import All to Shopify for the fetched products.
  4. Read the result on each card. Already imported products are skipped; failed imports can be retried after fixing the reported issue.
  5. Find successful imports under Imported Products. Out-of-stock variants may also appear in Awaiting Stock.
06. Edit products and understand base prices
  1. Open Imported Products, find the product, and select the edit icon in Actions.
  2. Ali Sale Price (Base) is the AliExpress sale price used as the base for app price calculations before your adjustments. A range means variant prices differ.
  3. Update the custom title, description, or rating as needed. Review the Shopify variant prices and edit the prices you want to change.
  4. Use Map supplier variants when Shopify variants need to be linked to the correct AliExpress variants. Match options such as size and color carefully.
  5. Select Save Changes and read the result to confirm whether changes were synced to Shopify.
07. Price sync, increases, and locks
  1. Check the product's Mode badge. Auto uses supplier base prices; an increase adds your configured amount; manual settings use your chosen variant pricing rules. Paused means price tracking is off.
  2. Use Increase Price to configure an adjustment. For example, a $10 base price with a $3 increase becomes $13.
  3. Use the edit form for individual variant prices and available price locks. Locked prices are skipped by automatic price updates.
  4. Select Sync Price to request a price update now. Review the result and your Shopify prices.
  5. For a bulk increase, select the intended rows first, then use Bulk Increase Price. Check the selected count before applying it.

Pricing tools require full product access. Hover or focus the mode badge for more details about the current rule.

08. Awaiting Stock and inventory
  1. Open Awaiting Stock and filter by status. Fully OOS means out of stock; Partial OOS means only some variants are out of stock.
  2. Expand the variant list to inspect stock and prices. Review the last-checked time and retry count.
  3. Select Retry to check stock now. The queue also supports automatic processing when stock returns.
  4. Use the edit icon to open an existing imported or mapped product. A queue-only product becomes editable after it is imported or mapped.
  5. For existing imports, use inventory sync in Imported Products or Settings. If AliExpress does not expose stock, the app may skip that stock update.
09. Sync Old Products: link existing Shopify products

When to use: You already have a product in Shopify and want to connect it to an AliExpress listing in AliSync so you can manage price and stock syncing. This creates a supplier link for the existing Shopify product.

Example: You added a shirt to Shopify manually. Use Sync Old Products to link that shirt to its AliExpress supplier.

  1. Select the correct store, then open Sync Old Products.
  2. Enter its AliExpress product ID or URL and Shopify product ID or admin URL. Add an optional title and select Add Mapping.
  3. Find the new mapping in the table. Open its editor and use Map supplier variants to review the supplier-to-Shopify variant links. Match options such as color and size carefully.
  4. Configure price tracking and pricing rules for products with full access. Use the row actions or Sync All Now when ready, then check the result in Shopify.
  5. Use search to find mappings, and select rows before applying a bulk price increase.

How it differs from remapping: Sync Old Products sets up the link for an existing Shopify product. Remapping replaces the AliExpress listing on a product already linked in AliSync. Both keep the existing Shopify product.

10. Remapping: change a linked AliExpress listing

When to use: A product is already imported or linked in AliSync, and you need to replace its AliExpress supplier listing, for example because the old listing stopped working or the supplier relisted it under a new ID. Remapping keeps the existing Shopify product and pricing rules.

Example: Your Shopify shirt is linked to AliExpress listing A, but the supplier now sells it under listing B. Remap the existing product from A to B.

  1. Find the product in Imported Products or Sync Old Products. You can also open Dead Listings and select Scan Dead listed products to check supplier availability.
  2. For a flagged listing, review the failure reason and verification status. Use Verify to recheck it. A warning is not yet a confirmed dead listing; the app requires repeated confirmation before inventory protection.
  3. Check that the replacement listing has the intended product and options. Select the row's Remap to new AliExpress ID icon and enter the replacement AliExpress product ID or URL.
  4. Select Remap Listing for an imported product or Remap for an existing-product mapping. Read the result to check whether the relink and Shopify updates succeeded.
  5. Open the product editor and review Map supplier variants to ensure each Shopify variant matches the intended replacement variant. Check the resulting prices and inventory in Shopify.

Variant mapping is different: Map supplier variants connects individual options, such as a red shirt in size M, within the linked listing. Remapping changes the AliExpress product listing itself.

11. Notifications and preferences
  1. Open Notifications or the bell icon to review stock, price, supplier, and potential-loss alerts.
  2. Use the available filters to find relevant alerts. Open a product's editor or sync action from an alert when available.
  3. Open notification preferences to set in-app and email alerts, low-stock thresholds, large-price-change thresholds, and minimum profit.
  4. Review the options for automatic inventory restoration and pausing large price updates before enabling them.
  5. Mark reviewed alerts as read. Email alerts require email delivery to be configured by the app administrator.
12. Settings, stores, and troubleshooting
  • Dashboard: review store totals, recent products, and health information; use refresh to update the overview.
  • Multiple stores: use the top-bar store selector to switch stores and its settings button to manage them. Confirm the active store before importing or syncing.
  • Missing stock tracking: in Settings, run Scan & Queue OOS Products to find existing imports with out-of-stock variants.
  • Missing images or SKU details: use the SKU variant image backfill or Backfill SKU Data. These jobs run in the background.
  • Inventory refresh: use Sync All Inventory Now in Settings, then review products and notifications for results.
  • Connection errors: check the account connections banner, store domain, installed Shopify app permissions, and AliExpress authorization. If Shopify reports missing permissions, release the updated app version and approve it on the store before retrying.
  • Feature unavailable: check your plan and the product's Basic/Full access status.

Backfill OOS to Pending Queue
Scan all imported products and queue those with out-of-stock variants

Run this once to catch any products already imported to Shopify that have OOS variants. They'll appear in the Awaiting Stock queue and auto-update inventory when stock returns.

Backfill SKU Variant Images
Upload AliExpress per-variant images to existing Shopify products

Run this once to add colour/size swatch images to variants on products already imported to Shopify. New imports will get SKU images automatically. This scans all imported products and attaches any missing variant images in the background.

Dead Listing Scanner
Find products whose AliExpress ID was relisted under a new ID

When AliExpress suppliers relist a product under a new ID, the old ID stops returning prices. This scan flags all such products. Once found, use the Remap button to point them to the new ID — prices, inventory, and Shopify metafields are all updated automatically.

Bulk Sync Inventory to Shopify
Push live AliExpress stock to ALL imported products at once

Fetches current stock from AliExpress for every imported product and pushes it to Shopify in one background job. Products where AliExpress doesn't expose stock (DS API hidden) are skipped automatically. Check terminal logs for per-product progress.

Backfill SKU Data
Fetch AliExpress SKUs for all imported products (so the Increase column works)

This will fetch fresh SKU data (prices, labels, stock) from AliExpress for every product that has a Shopify ID. Runs in the background – check terminal for progress.

Dead Listing Scanner — Mappings
Same scan, but for products linked via Product Mappings

Scans every entry in Product Mappings (not Imported Products) for dead AliExpress IDs. Dead mappings get flagged and their Shopify inventory is automatically zeroed until you remap them.
